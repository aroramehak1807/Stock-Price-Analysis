# Stock Price Analysis Dashboard

A web-based financial dashboard designed to fetch, analyze, and visualize historical stock price trends. Users can input any standard stock ticker symbol to retrieve real-time metrics and view trend visualizations over custom intervals.

## Features

* Dynamic Ticker Search: Input any valid stock symbol (e.g., AAPL, GOOGL, MSFT) to dynamically load market data.
* Key Performance Metrics: Displays essential financial figures at a glance, including Latest Close price, Daily Percentage Change, and Previous Close price.
* Interactive Data Visualization:*Integrates clean line charts tracking the stock's closing prices over time to analyze trends and historical volatility.
* Responsive User Interface: Built with a clean, dark-themed dashboard layout for clear data readability.
